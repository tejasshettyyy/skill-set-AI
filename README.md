# SkillSphere: AI-enabled Skill Intelligence & Learning Platform

Smart India Hackathon 2026, Problem Statement SIH26101 (Smart Education, Software).

SkillSphere maps each official's role to required competencies, detects skill gaps, recommends personalised learning, assesses mastery with AI-generated quizzes, and updates the competency profile continuously.

## The problem

Officials have profiles (skill, experience, role) and many learning resources, but skill gaps are not continuously identified and training outcomes are not continuously measured. Departments cannot see workforce capability or role-readiness.

## How it works

Official Profile -> Competency Mapping -> AI Skill-Gap Detection -> Personalized Learning -> AI Assessment -> Competency Update (repeats)

## Features

- Competency dashboard with role-readiness score
- Skill-gap analysis against role benchmarks
- Personalised learning paths (iGOT Karmayogi / NSSTA course matching)
- AI quiz generator from PDF / PPT / video content
- Progress and analytics views for officials, trainers and administrators

## Tech stack

| Layer | Technology |
|---|---|
| Frontend | React + Vite + TypeScript + Tailwind CSS |
| Backend | Python + FastAPI (planned / in progress) |
| AI | LLM + NLP + recommendation engine |
| Data | PostgreSQL / MySQL |
| Integration | REST APIs + SSO |

## Project status

Partially implemented. The frontend dashboard prototype is built; backend and AI modules are in progress.
